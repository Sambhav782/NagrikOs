# NagrikOS

**Government services, made understandable and accessible.**

NagrikOS is a multilingual citizen-services assistant for discovering government schemes, understanding eligibility, preparing documents, and finding verified public-service updates.

## Planned stack
- React + Vite + Tailwind CSS frontend
- Node.js + Express API
- MongoDB when `MONGODB_URI` is configured
- Curated demo data for local development

## Features
- Scheme discovery and eligibility guidance
- Document checklists
- Government shorts and public events
- Personalized alerts
- Hindi and English interface
- Clear links to official sources

Initial project setup in progress.
